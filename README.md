# Disney+ Tela Cheia Automática

Esta extensão foi feita para ajudar quem assiste Disney+ e quer deixar tarefas repetitivas no automático, sem precisar levantar para clicar toda hora.

## O que ela faz

- tenta voltar para a tela cheia quando o episódio muda
- tenta clicar em pular introdução, abertura ou resumo quando isso aparece
- pode clicar em próximo episódio automaticamente, se você quiser
- permite ligar e desligar as funções com um clique
- deixa você escolher se quer repetir a tentativa enquanto o próximo episódio carrega

## Como instalar

1. Abra o Chrome ou o Edge.
2. Na barra de endereço, digite `chrome://extensions` ou `edge://extensions`.
3. Ligue o `Modo do desenvolvedor`.
4. Clique em `Carregar sem compactação`.
5. Escolha esta pasta: `C:\Users\whois\Desktop\extensao`.
6. Pronto. O ícone da extensão vai aparecer no navegador.
7. Se o ícone não aparecer na barra, abra a área de extensões do navegador e fixe a extensão.

## Como usar

1. Abra a Disney+ no navegador.
2. Comece um filme ou uma série.
3. Clique no ícone da extensão.
4. Deixe `Automação geral` ligado.
5. Deixe `Tela cheia ao trocar episódio` ligado.
6. Se quiser, ligue `Pular introdução`.
7. Se quiser, ligue `Próximo episódio`.
8. Se quiser insistir mais durante o carregamento, deixe `Repetir tentativa` ligado.

## O que significa cada opção

- `Automação geral`: liga ou desliga tudo.
- `Tela cheia ao trocar episódio`: tenta voltar para a tela cheia quando entra o próximo episódio.
- `Pular introdução`: tenta clicar quando aparece pular introdução, abertura ou resumo.
- `Próximo episódio`: tenta clicar quando aparece a opção de ir para o próximo episódio.
- `Repetir tentativa`: faz novas tentativas por alguns segundos enquanto o vídeo muda.
- `Modo de verificação`: só use se quiser checar melhor o funcionamento.

## Se não funcionar de primeira

- confira se a extensão está ligada
- confira se você está assistindo pelo navegador
- tente sair e entrar na página novamente
- em alguns casos, o navegador pode pedir uma ação manual antes de aceitar tela cheia

## Aviso

Esta extensão foi pensada para uso pessoal, para deixar a experiência mais prática no Disney+.
