# Disney+ Tela Cheia Automatica

Esta extensao foi feita para ajudar quem assiste Disney+ e quer voltar para a tela cheia sem precisar levantar para clicar toda hora.

## O que ela faz

- tenta voltar para a tela cheia quando o episodio muda
- permite ligar e desligar as funcoes com um clique
- deixa voce escolher se quer repetir a tentativa enquanto o proximo episodio carrega

## Como instalar

1. Abra o Chrome ou o Edge.
2. Na barra de endereco, digite `chrome://extensions` ou `edge://extensions`.
3. Ligue o `Modo do desenvolvedor`.
4. Clique em `Carregar sem compactacao`.
5. Escolha esta pasta: `C:\Users\whois\Desktop\extensao`.
6. Pronto. O icone da extensao vai aparecer no navegador.
7. Se o icone nao aparecer na barra, abra a area de extensoes do navegador e fixe a extensao.

## Como usar

1. Abra a Disney+ no navegador.
2. Comece um filme ou uma serie.
3. Clique no icone da extensao.
4. Deixe `Automacao geral` ligado.
5. Deixe `Tela cheia ao trocar episodio` ligado.
6. Se quiser insistir mais durante o carregamento, deixe `Repetir tentativa` ligado.

## O que significa cada opcao

- `Automacao geral`: liga ou desliga tudo.
- `Tela cheia ao trocar episodio`: tenta voltar para a tela cheia quando entra o proximo episodio.
- `Repetir tentativa`: faz novas tentativas por alguns segundos enquanto o video muda.
- `Modo de verificacao`: so use se quiser checar melhor o funcionamento.

## Se nao funcionar de primeira

- confira se a extensao esta ligada
- confira se voce esta assistindo pelo navegador
- tente sair e entrar na pagina novamente
- em alguns casos, o navegador pode pedir uma acao manual antes de aceitar tela cheia

## Aviso

Esta extensao foi pensada para uso pessoal, para deixar a experiencia mais pratica no Disney+.
